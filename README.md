# OfflineInsiderEnroll-Mod

>  **Notice**: This is a modified clone of [OfflineInsiderEnroll](https://github.com/abbodi1406/OfflineInsiderEnroll) by **abbodi1406**.

##  Features
* **Bypass Restrictions**: Skip TPM 2.0, CPU, RAM, Secure Boot & Storage checks.
* **Canary & Dev Support**: Fully compatible with latest Windows 11 builds.
* **Fix Update Errors**: Built-in WU cache & telemetry reset (Option 6).
* **No Account Required**: Join Insider channels without a Microsoft Account.

##  How to Use
1. Right-click `OfflineInsiderEnrollmod.cmd` -> **Run as Administrator**.
2. Select your channel or fix option from the menu.
3. Reboot your PC if required.
